4. 为什么不使用12%作为统一正式值
==================================================

固定解释：

12% 来自以中国陆上 CO2-EOR 油田为对象的
技术经济评价设定。

本研究则评价：

capture source
+
transport
+
EOR/storage
+
alternative organizational structures

组成的完整 CCUS value chain。

因此使用：

8% integrated-system benchmark

而不是把：

EOR-specific 12%

扩展到整个 CCUS 链。

这属于：

scope-consistency decision

不是因为8%产生更高NPV。
