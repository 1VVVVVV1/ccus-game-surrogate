用户决定：取消 Li Fig.5 作为正式 EOR 产油量/收益校准依据。

正式采用一个透明的固定换油率假设：

4 tCO2 injected / 1 t incremental oil

即：

eor_co2_oil_ratio
=
4.0 tCO2 / t-oil

status:
MODEL_ASSUMPTION

==================================================
1. 正式产油量公式
==================================================

本模型中 EOR 路径的 CO2 注入量使用：

q_u

q_u 的单位：

tCO2/year

定义增量产油量：

Q_oil
=
q_u / 4.0

单位：

t-oil/year

即：

每注入4吨CO2，
产生1吨增量原油。

不得再从 Li Fig.5 的 oil-production curve
推导正式产油量。

==================================================
2. 正式EOR收益公式
==================================================

若油价定义为：

P_oil
=
CNY / t-oil

则：

EOR revenue
=
Q_oil * P_oil

=
(q_u / 4.0) * P_oil

因此可以直接写成：

EOR revenue
=
q_u * (P_oil / 4.0)

所以模型中的：

utilization_revenue_per_ton

正式定义为：

utilization_revenue_per_ton
=
P_oil / 4.0

单位：

CNY / tCO2

==================================================
3. 与现有B_u公式衔接
==================================================

当前利用端议价中的：

B_u
=
P_o - c_u

其中正式令：

P_o
=
P_oil / 4.0

因此：

P_o

不再理解为：

oil price itself

而是：

gross EOR revenue attributable to one tonne of fresh CO2
routed to the EOR pathway.

==================================================
4. q_u就是正式收益分母/物理基数
==================================================

只使用：

q_u

计算增量油收益。

不得把：

recycled CO2

再次加入收益侧注入量。

即：

Q_oil
=
q_u / 4

而不是：

(q_u + recycled_CO2) / 4

原因：

本模型q_u表示外部新CO2进入EOR商业路径的流量，
内部回收CO2不形成新的外部CO2交易或新的q_u。

==================================================
5. xi的作用
==================================================

基准：

Q_bar = 0.50 Mt/year
xi = 0.20

在双方均已建设且无交易约束时：

q_u
=
0.20 × 0.50
=
0.10 MtCO2/year

因此：

incremental oil
=
0.10 / 4
=
0.025 Mt-oil/year

即：

25,000 t-oil/year

这个只是由模型假设推导出的基准产油量，
不是齐鲁—胜利项目实测产量。

==================================================

正式收益映射：

Oil output:
Q_oil = q_u / 4

Gross EOR revenue:
R_EOR = (q_u / 4) * P_oil

Equivalent per-ton-CO2 revenue:
P_o = P_oil / 4
